# 星璇（Andromeda）桌宠

蓝发与星饰，安静陪在桌面一角。星璇是一款 Windows 桌宠，支持拖动、边缘收纳、缩放和轻互动，默认保持安静，偶尔做一个小动作。

角色采用 **3D 风格的透明 2D 图像**。项目提供 Windows 免安装程序、源码与独立角色图集。

![星璇](assets/neutral.png)

## 快速开始

1. 前往 [v0.2.0 下载页面](https://github.com/chenyihang98-pixel/andromeda-desktop-pet/releases/tag/v0.2.0)，选择 `Andromeda-0.2.0-windows-x64-portable.zip`
2. **完整解压**到一个新文件夹，不要只取出 `.exe`，不要在旧进程运行时覆盖旧目录
3. 双击 `Andromeda.exe`。无需安装 Node.js，也无需安装器
4. 拖住角色移动；双击角色或点击悬浮的 `⋯` 打开设置
5. 右键角色或系统托盘图标打开菜单；点托盘图标可显示角色并解除停靠、关闭点击穿透；菜单或设置内可明确退出

当前为 v0.2.0 开发版，面向 Windows 10/11 x64，尚无代码签名。若 Windows 阻止执行，请先核对发布来源和随包 SHA-256；不要关闭系统安全防护。旧版发行及附件继续保留。

## 新增：藏进屏幕边缘

- 默认开启「边缘收纳」。拖动后在当前显示器工作区的左、右、上、下边缘附近松手，角色收起，只留下一个星形小把手
- 吸附距离为 18 个逻辑像素（DIP）；以不含任务栏的工作区为准。跨屏移动过程中不会提前吸附，只有松手才判断停靠
- 鼠标移到把手上就展开；移开约 0.7 秒后收回。快速移回会取消收回；打开设置或角色右键菜单时不会收回
- 如果松手时鼠标恰好落在把手上，先移开再移回，避免刚收起就立即弹出
- 展开后拖向屏幕内侧即可脱离。点击把手、按 Esc（窗口获得键盘焦点时）、点托盘图标或「重置位置」也能恢复自由放置
- 真正的窗口会缩小为把手大小，不把透明大窗口藏到隔壁显示器里；不会用整条屏幕边缘拦截点击
- 关闭「边缘收纳」会解除停靠。重启时始终显示完整角色，不记住收起状态

## 陪伴与桌面功能

- 透明无边框窗口、默认置顶、拖动、75%–200% 缩放
- 默认「安静」：保持中性站姿 45–90 秒后轻动一次；无自动走动、无快速眨眼循环
- 「静止」关闭自主动作；「轻快」将间隔缩至 12–20 秒；挥手、小跳、等候、检查可手动触发
- 可选近距离注视；新增可选「全桌面注视」，每秒最多约 10 次读取本机鼠标方向，不记录轨迹、不传到网络。开启后以静态注视替代自主小动作，仍可手动互动
- 新增整窗点击穿透，默认关闭。启用后点击落到背后应用；**点托盘图标即可关闭穿透**。托盘不可用时禁止开启；停靠时暂停穿透，重启时自动关闭
- 锁屏或系统休眠时隐藏并暂停；解锁且系统恢复后还原。手动隐藏的角色不会被自动唤回，恢复时不抢焦点
- 断开显示器、工作区或 DPI 改变时重新计算可见位置；所有窗口与鼠标坐标统一使用 DIP
- 单实例；本地保存大小、节奏、位置、置顶和注视等设置；遵循系统减少动画偏好；隐藏和收起时停止动画计时
- 「检查新版本」只打开本仓库发行页，由你选择下载，不在后台联网查询、不自动安装或执行下载文件

本版无聊天、AI 模型、语音、账号、遥测或开机自启。默认关闭穿透时，透明窗口的矩形区域仍会接收鼠标；穿透是整个窗口的开关，**不是透明像素自动穿透**。全桌面注视关闭时，仅在停靠把手或穿透恢复保障需要时读取鼠标位置。

「便携」指免安装解压运行。设置保存在 Windows 用户数据目录的 `Andromeda` 文件夹中，不写回压缩包目录；通常为 `%APPDATA%\Andromeda\settings.json`。v0.1.0 设置可直接读取，新功能采用安全默认值；关闭程序后删除该文件可重置设置。

## 开发与构建

使用 Node.js 22.12+（建议受支持的 LTS）和 npm。首次安装与构建需要网络访问 npm / Electron 官方发布源；除主动打开版本页面外，应用自身运行不需要网络。

```sh
npm ci
npm run verify
npm start
npm run build:win
npm run pack:assets
```

`build:win` 生成 Windows x64 ZIP 及 `dist/SHA256SUMS.txt`，不会自动发布。依赖与锁文件固定；ZIP 时间戳等可能随机器不同，不承诺逐字节相同。v0.2.0 仅保留中文和英文的 Electron 内置语言资源，并采用最大 ZIP 压缩；不删除安全组件或许可证，不声称变成轻量原生程序。Windows 图标与版本资源已纳入构建，代码签名仍未启用。

```sh
# 已安装 Chromium 的开发环境，需要允许本地测试服务和浏览器进程
CHROMIUM_PATH=/usr/bin/chromium npm run test:ui
```

测试脚本的存在不等于实机验证通过；本次准确记录及 Windows 验收清单见 [测试说明](docs/TESTING.md)。

## 仍然存在的限制

- 无签名开发包仍可能触发 SmartScreen。代码签名需要发布者身份与证书，无法靠改代码消除；本版只有手动版本检查入口，没有自动更新
- 当前只提供 Windows x64 包。macOS、Linux、Windows ARM64 未作为本次已验证发行平台
- 已缩减语言资源，但 Electron 运行时仍占大部分体积；大幅减重需评估原生/其他框架迁移
- DPI、负坐标和断屏已有自动化回归，但 v0.2.0 的真实 Windows、多屏混合 DPI、远程桌面、锁屏和休眠仍需实机验收；极小工作区与系统合成器差异可能影响显示
- **没有其他应用全屏自动隐藏**。Electron 的本窗口全屏事件不能可靠识别其他应用；后续需 Windows 原生前台窗口检测及游戏/视频/多显示器验收。现在可从托盘暂时隐藏，或关闭置顶
- 没有按透明像素自动穿透；只有可恢复的整窗穿透
