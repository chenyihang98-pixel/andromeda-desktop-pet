# 星璇视觉制作规格 v1

2026-10-22。这是后续素材的统一制作与验收基准；已有生成参考尚未逐格全部达标。

## 身份母版

原始 `assets/andromeda.png` 是身份来源，原始中性站姿 `assets/neutral.png` 是小尺寸识别基准。保留蓝色长发、蓝眼睛、金色星形头饰、白蓝连衣裙、白色短靴与圆润的 3D 渲染质感。金星固定在**角色自身左侧**；左右视角、左右行走与指向不可直接镜像。

下列色值是制作目标，不宣称生成图每个像素都精确符合：头发主色 `#235CDC`、阴影 `#1D317A`、高光 `#85B7FF`；眼睛 `#3978B3`；金星 `#E7BD54`；衣服白 `#F3F7FC`、蓝饰边 `#5B91CB`；短靴 `#F3F1EA`，细节沿用母版。面板与气泡独立于角色服装：夜空 `#101624`、清晨暖光、节日金色。

比例目标为约 2.4–2.8 头身；头饰大小、眼距、发梢长度与裙摆层数以母版为准。正面/左右四分之三/左右侧面/背面要保持同一角色体积，不把左右头饰画成两颗星。背面应清楚交代头发层次、衣领和裙摆，避免用正面五官贴背面。

## 姿态与表情清单

六视角参考为 `assets/studio/turnaround-v2.png`，1536×1024；十二姿态为 `assets/studio/life-poses-v1.png`，1254×1254、4列3行。后者格宽313.5不是最终动画生产网格，只作为可切换的静态参考；禁止把它标成十二组连续动画。

| 类别 | 必须保持的可读特征 | 当前情况 |
|---|---|---|
| 中性/眨眼 | 放松肩膀，眼睛开合不改变眼距 | 经典动画可用，新图只有静态 |
| 开心/庆祝 | 眼眉和身体一起变化，脚底有明确起落 | 有静态开心及经典小跳 |
| 思考 | 视线、手势可辨，避免与跑步混淆 | 新图静态思考；经典有回退 |
| 疑惑 | 单侧歪头/眉毛差异，区别惊讶 | 尚缺独立统一母图 |
| 惊讶/提醒 | 嘴和眉有变化，不过度受惊 | 有静态姿态 |
| 困倦/睡觉 | 身体重心降低，进入/离开可衔接 | 有静态坐睡，缺过渡帧 |
| 温和失落 | 克制表情，不用负面情绪催促用户 | 尚缺独立母图 |
| 被摸/感谢 | 手与头部关系自然，发丝不穿插 | 有静态反应，缺连续帧 |

下一批连续动作按进入→保持/循环→退出制作：坐下/起身、睡下/醒来、阅读翻页、思考、挥手、伸懒腰、左右行走、拖起/放下、抛掷落地、收起/展开、左右指向、说话。每个动作至少检查首尾接缝与中间关键帧，不能用重复静态帧充数。

## 输出与验收

- 工作母图用独立透明 PNG，禁止外加落地阴影烘焙成大块背景。角色实心区域应接近完全不透明，发梢保留合理抗锯齿。
- 生产图集用可整除的整数网格；每帧统一镜头、比例与脚底。角色包写清 cellWidth/cellHeight、动作帧数/时长和 ground 锚点，不能依赖隐含坐标。
- 桌面高清目标每帧384×416或更高同等比例；网页标准档192×208，并保留轻量档。实际产物以质量、传输和设备测量决定，不先承诺尚不存在的多档素材。
- 在透明棋盘、纯白、纯黑、夜空与清晨背景分别看75%、100%、150%、200%。检查蓝白毛边、孤立像素、脚被裁切、头饰跳动和阴影突然变化。
- 静态分格也必须逐格对齐；命中测试采样当前可见角色 alpha。透明矩形不能算作角色身体。
- 经典默认外观不受新素材实验影响。新姿态当前仍有少量蓝白散边，保持可选，并在修复验收前明确标为静态试验外观。
