# 星璇素材格式与 ChatGPT Pets

本说明对应 2026-10-03 验证的现有图集。素材是带 alpha 的 2D PNG，不是 Live2D、VRM、MMD、FBX 或 3D 模型。

## 文件

- `andromeda.png`：1536×2288 RGBA，SHA-256 `8007f0c1c212ec2c950a92af4c8648d6eab66b61e7d998b702e452b3e7b1040d`
- `manifest.json`：`andromeda.sprite-atlas/v1`，记录尺寸、动画行、时长及桌面播放参数
- `neutral.png`：原图 row 0 / column 0 的原尺寸裁切，仅供展示

图集按 8 列 × 11 行组织，每格 192×208。坐标从左上角开始、行列均从 0 开始。裁切矩形为 `(column × 192, row × 208, 192, 208)`。保持整格的对齐与透明度，不要逐帧重新裁掉空白或独立缩放。73 格有图像，另 15 格保持透明。

## 本桌宠的播放策略

本项目在原始帧数据外增加安静调度，默认中性保持 45–90 秒后播放一次 idle，帧时长乘 1.5；互动动作也乘 1.5，然后回到中性。静止模式无自主定时器；轻快模式保持 12–20 秒。自动走动与额外眨眼均关闭。系统减少动画偏好会取消自动动作，并将手动动作改为短暂静态姿态。

`docs/preview.gif` 是已有图集的预览，不能代表桌面默认45–90秒的实际间隔。默认桌宠以本项目的 playback 参数为准。

## 在 ChatGPT Pets 中复用

该 PNG 对应当前 `spriteVersionNumber: 2`：8×11 格，尺寸必须保持 1536×2288，透明 PNG / WebP，文件不超过 20 MiB。

在具备 ChatGPT Pets 功能及素材导入工作流的环境中，提供 **原始 PNG** 并明确请求校验、导入新宠物或更新指定现有宠物。应先校验完整图集，再经该环境当前支持的导入流程操作。更新现有宠物时保留其已有身份，不要意外创建重复宠物。

`manifest.json` 是本项目的可读交换格式，不是 ChatGPT 客户端通用设置文件；它不能改变 ChatGPT 宿主的动作调度，也不保证在其界面直接拖入可用。不要把桌面程序的45–90秒播放节奏当作宿主承诺。各版本界面入口及导入能力可能不同，以实际支持为准。
