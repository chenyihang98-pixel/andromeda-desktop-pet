原生重开测试首次执行发现测试本身未等待旧窗口关闭，已改为等待 `closed` 并确认新窗口 ID 后再检查；最终 27 项通过。构建和分支预览另做产物校验。测试使用隔离 QA 资料，不读取主人存档；模型、录音、原生文件选择器按各探针说明模拟，不表示外部提供商或麦克风听感已验收。

显示比例继续保留经典、Studio、自定义图集等比取样与小工作区适配。当前真实显示器为 1280×720 DIP、工作区 1280×680 DIP、150% 缩放；分辨率和多屏矩阵包含模拟，真实混合 DPI、多屏热插拔、锁屏/睡眠、RDP、手机软键盘与其他 OS 仍需设备验收。

本轮没有修改角色原图，`assets/andromeda.png` SHA-256 为 `8007f0c1c212ec2c950a92af4c8648d6eab66b61e7d998b702e452b3e7b1040d`。六视角与十二姿态仍是静态素材，透明蓝边和角色细节还需美术清理。54 项路线图仍为 20 项基础完成、28 项部分完成、4 项外部依赖、2 项未实现。
