## 打包与发布边界

本地Windows构建使用 `electron-builder --win zip --x64 --publish never --config.compression=normal`，压缩档与源码默认maximum不同，只影响体积/构建时间。生成物在 `dist/Andromeda-0.3.0-windows-x64-portable.zip`，对应校验和在 `dist/SHA256SUMS.txt`。不得把中断的压缩临时文件作为交付；最终包需完成ZIP解压校验与ASAR资源核对。

程序仍未签名，更新仍为手动检查。尚未执行真实提供商聊天/ASR/TTS、麦克风听感、实际锁屏/睡眠、多屏热插拔、其他DPI、手机软键盘、macOS/Linux或原生游戏兼容验收。没有自动注册系统协议、启动用户应用或修改开机启动；这些需在用户主动开启的已打包程序里验收。

三项审阅缺口已修：锁屏时宿主直接归零音乐位移；自定义角色离开/关闭注视后回静止；经典注视遵守应用内减少动态。另补取消在语音设备/音频上下文准备期间的迟到保护。每项缺失与扩展范围继续保留在 [54项实施核对表](IMPLEMENTATION-STATUS.md)。

本地探针JSON、截图、构建日志位于忽略目录 `qa/`；不把模拟、原生探针、实际服务或公开发布混成一个“全通过”结论。
