`npm run verify` 包括设置迁移、托盘/设置恢复、手动隐藏、锁屏与休眠叠加、辅助进程错误/超时/迟到消息、负坐标和物理像素到 DIP 映射的回归测试。Windows 上还会编译自有检测工具，运行纯策略样例并检查真实元数据心跳与关闭管道后的退出。策略样例不等于真实全屏检测通过；适配器中的锁屏、DPI 和焦点断言也不等于对应原生环境通过。
