## Windows v0.2.0 验收清单（待实机执行）

每项记录操作系统版本、显示器布局、DPI、程序版本/提交及通过或失败结果：

1. 首启、关闭再启动、旧版设置迁移；始终能看到完整角色，穿透关闭
2. 左右上下四边与四角，任务栏分别在各边；把手不压住任务栏，不出现邻屏幽灵输入区域
3. 松手收起；悬停展开不抢焦点；离开约 0.7 秒收回；延迟期间移回取消；松手落在把手时移开再移回
4. 展开后向内拖动脱离；点击把手、Esc（有焦点）、托盘显示、重置位置、关闭边缘收纳都能恢复
5. 拖动跨屏时不提前吸附；取消指针、失焦、打开菜单和超时不会意外停靠；快速按下/松开与多次重复操作稳定
6. 75%–200% 应用大小及 100/125/150/200% Windows 缩放；两块不同 DPI 的屏幕，副屏位于主屏左侧/上方
7. 收起与展开时调整工作区、旋转/断开显示器、重连远程桌面；角色仍可找回，重启锚点不是小把手位置
8. 设置/右键菜单打开时不自动收回；关闭后重新开始离开延迟；小屏上设置面板可滚动到退出按钮
9. 普通/收起/手动隐藏/穿透/拖动中分别锁屏与休眠；锁屏和休眠事件两种先后顺序；恢复不抢焦点，不唤回手动隐藏的角色
10. 开启整窗穿透，确认点击落到后面应用；点托盘恢复；退出重启默认关闭；托盘不可用时禁止开启
11. 全局注视默认关闭；开启后没有自主动画，手动动作完整播放；减少动画偏好下不持续转头；隐藏/锁屏/收起暂停
12. 隐藏和收起状态下仍可明确退出；所有窗口关闭后无不可见孤立进程；退出时没有待执行恢复计时器
13. 检查新版本只打开本仓库发行页；程序不后台下载或安装；核对源文件、压缩包内容、SHA-256 和 Windows 文件属性中的版本/图标

其他应用全屏自动隐藏、自动更新、签名、Windows ARM64/macOS/Linux 和逐透明像素穿透均不属于本版已完成或已通过项目。后续方案和验收标准见 [英文 Codex 续做清单](CODEX-HANDOFF.md)。
