当前实际显示器：单屏 1280×720 DIP、工作区 1280×680 DIP、150% 缩放。分辨率矩阵包括 720p、768p、1080p、1440p、4K、超宽和竖屏，但多屏/DPI 组合是模拟，不声称接了全部物理屏幕。真实混合 DPI 拖动、热插拔、锁屏/睡眠、RDP、手机软键盘和其他 OS 仍待设备验收。

探针使用隔离 QA 资料与合成内容，不读取主人存档。原生应用探针故意从公开角色窗口请求私人 IPC 并验证拒绝；输出中对应拒绝日志是预期结果。模型/语音接口使用模拟，没有执行真实提供商、麦克风听感或外部账号同步验收。全屏探针必须用 Node 启动；一次用 Electron 启动的错误调用已更正为上述命令并通过 4/4，不将错误调用当作产品失败。

最后审查还发现经典动作隐藏恢复后被 `neutral()` 覆盖，已统一恢复顺序并增加 22 条浏览器回归。域调度、渲染缓存、跨屏适配、页面销毁和资源释放均经过独立代码复核；公开 API 没有因为当前内部无调用就擅自删除。

原角色 `assets/andromeda.png` 的 SHA-256 保持 `8007f0c1c212ec2c950a92af4c8648d6eab66b61e7d998b702e452b3e7b1040d`。Studio 六视角与十二姿态还是静态素材，透明蓝边和角色细节仍需美术清理；本轮修正缩放算法不等于动画已制作完成。54 项路线图仍是 20 项基础完成、28 项部分完成、4 项外部依赖、2 项未实现。

## 构建和发布

Windows 使用 `npm run build:win`，固定 normal 压缩，生成 `dist/Andromeda-0.3.1-windows-x64-portable.zip` 与 `dist/SHA256SUMS.txt`。ZIP 完整性、ASAR 逐文件校验、构建后真实加载结果和源码身份见 [构建交接](BUILD-0.3.1.md)。程序未签名，公开 GitHub Release 仍为 v0.2.0。

网站 SDK 和展示优化推送集成分支并更新现有草稿 PR；不合并生产主分支。公开网站展示仓库同步注明“未发布”的记录，不把开发进度写成上线公告。

Cloudflare 分支预览已部署成功，并实取清单、13 个 SDK 文件及网站主 JS 与本地构建进行字节/哈希核对，全部一致。正式域名仍未合入这次改造；六页浏览器回归是在本地生产构建执行。

资源原始 JSON、截图和日志保留在忽略目录 `qa/`；报告统计与复现命令见 [资源与比例审查](PERFORMANCE-0.3.1.md)。
