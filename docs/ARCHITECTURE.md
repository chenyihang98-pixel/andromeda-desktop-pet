# 架构与安全边界

- Electron 主进程管理桌面窗口、托盘、显示器边界、设置文件和受限 IPC
- sandbox + contextIsolation 开启，nodeIntegration 关闭；渲染器只接触白名单桥接方法
- 本地协议只提供应用随附资源，外部网络、弹出窗口、导航、下载和权限申请被拒绝
- Canvas 按 manifest 裁切原始图集。没有逐帧重绘、模糊缩放补帧或角色生成
- 纯动画选择函数与计时分离，自动播放使用帧间定时器；中性保持和隐藏时不进行60fps空转
- 配置经过类型、范围和枚举校验；原子写入用户数据目录；损坏配置退回安全默认值
- 隐藏状态不跨启动保留；托盘不可用时禁止隐藏，避免角色无法找回
- 所有交互仅留在本机，无应用服务器、账号、遥测、远程代码或模型服务

桌面功能由 Electron / Chromium 与操作系统提供。验证记录见 [测试说明](TESTING.md)。
