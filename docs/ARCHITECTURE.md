# 架构与安全边界

## 职责划分

- `src/main.cjs` 管理窗口、托盘、系统状态、显示器、鼠标采样、本地设置和受限 IPC
- `src/docking.cjs` 是可独立测试的纯几何模块：4 边停靠、把手/完整角色边界、显示器选择和命中判断
- `src/settings.cjs` 校验配置并原子写入；v1 配置格式向后兼容，新增设置缺省为安全值
- `src/pet.mjs` 与 `src/animation.mjs` 按 manifest 裁切原始图集、安排低频动画；收起与隐藏时没有动画计时
- `src/settings-ui.mjs` 展示设置、可用性和恢复提示；渲染器没有文件系统或 Node 权限

## 边缘收纳与系统生命周期

停靠记录显示器 ID、边缘与沿边相对位置。展开是正常角色大小；收起时真实窗口缩为 14×64 或 64×14 DIP（极小工作区内会进一步约束）。两者都在 `workArea` 内，不把隐藏窗口移到相邻屏幕。拖动过程中不吸附；有实际位移并正常释放后才判断停靠。取消、失去捕获、失焦和超时结束拖动不会自动停靠。

停靠时以 100 ms 间隔读取本机指针，悬停恢复，不抢焦点；移开 700 ms 后收起，重新移入、打开设置或菜单取消收起。该计时器也供可选全桌面注视/穿透恢复保障使用，不重复创建。普通静置且相关功能关闭时不轮询；隐藏、锁屏、休眠、退出时停止。

位置保存始终使用完整角色的锚点，不能把 14 像素把手写成角色尺寸。停靠不跨重启保存，穿透每次启动强制关闭。`locked` 与 `suspended` 独立记录，只有全部解除后才恢复；用户主动隐藏是另一状态，不会被解锁覆盖。托盘或重置是明确的恢复路径。

屏幕、鼠标、窗口均使用 Electron 的 DIP，不额外乘显示器 DPI。显示器变动时重算停靠位置；目标屏幕消失时解除停靠并夹回剩余屏幕。

## 安全与隐私

- sandbox + contextIsolation 开启，nodeIntegration 关闭；IPC 验证发送窗口、顶层 frame URL、参数数量、类型、范围和白名单
- 本地协议只提供随附资源；应用 session 拒绝外部网络、弹窗、导航、下载和权限申请
- 唯一外部入口是用户主动点击「检查新版本」：主进程只用固定 HTTPS 本仓库发行地址调用系统浏览器，不接受渲染器 URL，不下载或执行升级程序
- 全局注视只读取指针方向，最多约 10 Hz；不监听按键、不截图、不记录鼠标轨迹、不上传数据；默认关闭
- 整窗穿透默认关闭，需要可用托盘；停靠中暂停穿透，点击托盘可关闭。相关原生 API 失败时尝试恢复可交互状态
- 设置校验与原子写入用户目录；损坏配置退回默认值。没有凭证、远程脚本、账号、遥测或后台更新
- 隐藏状态不跨启动保留；托盘不可用时禁止隐藏，保留任务栏入口

Electron 的公开 API 无法通用判断其他应用全屏，未用不可靠的窗口名猜测或截图绕过。相关后续范围见 [Codex 续做清单](CODEX-HANDOFF.md)。验证范围见 [测试说明](TESTING.md)。
