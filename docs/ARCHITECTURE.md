# 架构与安全边界

## 职责划分

- `src/main.cjs` 管理窗口、托盘、系统状态、显示器、鼠标采样、本地设置和受限 IPC
- `src/fullscreen-monitor.cjs` 管理可选 Windows 全屏检测子进程、受限心跳解析、超时和退出恢复；`native/windows-fullscreen.cs` 只读检测前台窗口
- `src/docking.cjs` 是可独立测试的纯几何模块：4 边停靠、把手/完整角色边界、显示器选择和命中判断
- `src/settings.cjs` 校验配置并原子写入；v1 配置格式向后兼容，新增设置缺省为安全值
- `src/pet.mjs` 与 `src/animation.mjs` 按 manifest 裁切原始图集、安排低频动画；收起与隐藏时没有动画计时
- `src/settings-ui.mjs` 展示设置、可用性和恢复提示；渲染器没有文件系统或 Node 权限

## 边缘收纳与系统生命周期

停靠记录显示器 ID、边缘与沿边相对位置。展开是正常角色大小；收起的目标尺寸为 14×64 或 64×14 DIP（极小工作区内会进一步约束）。Windows 可能强制更大的最小窗口，例如本机 200% 缩放下的 30×64 / 64×36 DIP。因此设置边界后读取真实尺寸，再按目标显示器工作区贴边和约束位置，不能假设 `setBounds` 请求值等于实际值；系统实际尺寸无法容纳时放弃停靠。把手填满实际紧凑窗口，不把隐藏窗口移到相邻屏幕。拖动过程中不吸附；有实际位移并正常释放后才判断停靠。取消、失去捕获、失焦、打开右键菜单和超时结束拖动不会自动停靠。渲染器只接受发起拖动的指针，并在结束或取消时释放捕获。

停靠时以 100 ms 间隔读取本机指针，悬停恢复，不抢焦点；移开 700 ms 后收起，重新移入、打开设置或菜单取消收起。该计时器也供可选全桌面注视/穿透恢复保障使用，不重复创建。普通静置且相关功能关闭时不轮询；隐藏、锁屏、休眠、退出时停止。

位置保存始终使用完整角色的锚点，不能把 14 像素把手写成角色尺寸。停靠不跨重启保存，穿透每次启动强制关闭。`locked` 与 `suspended` 独立记录，只有全部解除后才恢复；用户主动隐藏是另一状态，不会被解锁覆盖。托盘或重置是明确的恢复路径。

Electron 侧的屏幕、鼠标、窗口均使用 DIP，不额外乘显示器 DPI。显示器变动时重算停靠位置；目标屏幕消失时解除停靠并夹回剩余屏幕。全屏组件输出的物理坐标在专门的转换边界处理。

## Windows 全屏自动隐藏（实验功能）

当前源码包含此实验功能，已发布 v0.2.0 不含此功能。选项默认关闭，只在 Windows 且组件和托盘可用时允许开启。组件每 500 ms 检查一次前台顶层窗口，比较窗口、DWM 可见边框和客户区与所在显示器的物理边界，允许最多 2 像素舍入误差；同时排除普通最大化、最小化、不可见、cloaked、带边框/标题、子窗口、工具窗口、带所有者窗口、桌面/系统外壳及本应用窗口。它是保守识别，不能保证识别所有独占游戏、无边框游戏或播放器，也不会检测非前台的全屏窗口。

组件启用 Per-Monitor V2 DPI 感知，只输出版本号、全屏布尔值及命中显示器的物理矩形。主进程用 `screen.screenToDipPoint` 转换该显示器中心，再与角色所在显示器匹配；其他屏幕全屏不隐藏角色。不能直接把混合 DPI 的桌面原点乘缩放系数。

`fullscreen` 与 `locked`、`suspended` 分别作为暂停原因。自动恢复使用 `showInactive`，保留用户手动隐藏；锁屏、休眠、退出或关闭选项时停止组件。明确的托盘显示、重置位置、第二实例启动和手动动作会关闭自动隐藏；自动隐藏期间打开设置也会关闭选项，以保留可靠的恢复入口。托盘失效时关闭选项并保留任务栏入口。

主进程只执行固定的随附组件路径，以参数数组传递父进程 ID，不经过 shell，也不显示控制台。每条 JSON 心跳最多 1,024 字节，单次数据块最多 65,536 字节；字段和矩形整数范围均经过校验。重复有效心跳仍重新评估显示器与托盘状态。组件退出、输出异常或连续 3 秒没有有效心跳时解除全屏暂停并关闭选项；不自动循环重启。组件随父进程退出或输入管道关闭而退出，迟到事件不能重新隐藏角色。

`scripts/build-windows-helper.cjs` 使用 Windows 自带的 .NET Framework 4 C# 编译器；运行组件使用系统 .NET Framework 运行时，无新增第三方运行库包。Windows 上的 `npm start` 在开发启动前编译；打包钩子 `scripts/before-pack.cjs` 编译后通过 Windows `extraResources` 把组件放到 `resources/native/windows-fullscreen.exe`。已打包程序不下载或编译组件。当前仅支持 Windows x64 构建；从 Linux 交叉打包 Windows 会明确失败。

原生全屏窗口可能保留 `WS_MAXIMIZE` / `IsZoomed` 标志，因此不能仅凭该标志排除。普通最大化由标题/边框及客户区、可见边界是否覆盖完整显示器共同区分；自定义无边框窗口仍可能与全屏相似。

策略单元测试、子进程监督测试和浏览器测试不能证明 Windows 真实鼠标路由或全屏行为。完整原生验收仍须覆盖游戏（含独占模式）、视频、普通最大化、桌面/任务切换、第二显示器、混合 DPI、UAC 安全桌面、锁屏/休眠和 RDP，按 [测试说明](TESTING.md) 记录实际证据。

## 安全与隐私

- sandbox + contextIsolation 开启，nodeIntegration 关闭；IPC 验证发送窗口、顶层 frame URL、参数数量、类型、范围和白名单
- 本地协议只提供随附资源；应用 session 拒绝外部网络、弹窗、导航、下载和权限申请
- 唯一外部入口是用户主动点击「检查新版本」：主进程只用固定 HTTPS 本仓库发行地址调用系统浏览器，不接受渲染器 URL，不下载或执行升级程序
- 全局注视只读取指针方向，最多约 10 Hz；不监听按键、不截图、不记录鼠标轨迹、不上传数据；默认关闭
- 可选全屏组件只读取窗口状态、样式、类名及边界用于排除与判断，不读取标题、内容或可执行文件路径，不记录检测历史、不联网；无需管理员权限或新增第三方包
- 整窗穿透默认关闭，需要可用托盘；停靠中暂停穿透，点击托盘可关闭。相关原生 API 失败时尝试恢复可交互状态
- 设置校验与原子写入用户目录；损坏配置退回默认值。没有凭证、远程脚本、账号、遥测或后台更新
- 隐藏状态不跨启动保留；托盘不可用时禁止隐藏，保留任务栏入口

Electron 窗口自己的全屏事件不能用于判断其他应用；这里由项目自有 Windows 组件做有限范围检测。透明像素命中区域尚未实现，当前穿透仍针对整窗。签名与自动更新、其他平台和轻量实现的后续范围见 [Codex 续做清单](CODEX-HANDOFF.md)。验证范围见 [测试说明](TESTING.md)。
